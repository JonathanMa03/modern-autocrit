Clinical-distance penalty

Measure how far an observed trial value falls outside a target population. For example, compare an observed minimum age of 60 with a target age of 18. Values inside a target range have distance 0 and full relevance.

Tolerance is the clinically negligible difference. Distance scale controls how rapidly relevance falls; larger values penalize differences less severely.
